# MAAD Portfolio Site

A modern, responsive portfolio website showcasing design and development work. Built with HTML, CSS, and vanilla JavaScript.

## Features

✨ **Modern Design**
- Clean, minimalist interface
- Gradient backgrounds and smooth animations
- Responsive grid layouts

🎯 **Fully Responsive**
- Mobile-first approach
- Works seamlessly on all devices
- Touch-friendly navigation

⚡ **Performance Optimized**
- Lightweight vanilla JavaScript
- No external dependencies
- Fast loading times

🎨 **Interactive Elements**
- Smooth scroll navigation
- Hover animations
- Form validation
- Mobile hamburger menu

## Sections

- **Hero**: Eye-catching landing section with call-to-action
- **About**: Personal introduction and skills showcase
- **Projects**: Featured work in grid layout
- **Contact**: Contact information and message form
- **Navigation**: Fixed header with smooth scrolling
- **Footer**: Social links and copyright

## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/mohamedabdilaahi7270-dev/MAAD.git
cd MAAD
```

2. Open `index.html` in your browser:
```bash
open index.html
# or
start index.html
```

3. For local development with a server:
```bash
python -m http.server 8000
# or
npx http-server
```

Then visit `http://localhost:8000` in your browser.

## Customization

### Update Personal Information
Edit the following in `index.html`:
- Hero title and subtitle
- About section content
- Project details
- Contact information

### Change Colors
Modify CSS variables in `styles.css`:
```css
:root {
    --primary-color: #1a1a1a;
    --secondary-color: #ff6b35;
    --accent-color: #f7b801;
    /* ... */
}
```

### Add Projects
Duplicate a `.project-card` in the projects grid and update:
- Icon class
- Title
- Description
- Tags
- Link
